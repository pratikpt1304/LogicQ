# LogicQ End-to-End QA & Acceptance Test Plan (`/docs/TEST_PLAN.md`)

## 1. Testing Principles & Clean Environment Setup

1. **Zero Real Student Data**: All testing runs strictly against the **Firebase Local Emulator Suite** (or an isolated local test database), never touching real Sanjivani student records.
2. **Honest Reporting**: Every test execution is recorded in [`/docs/TEST_REPORT.md`](./TEST_REPORT.md) with columns: `ID | Feature | Steps | Expected Result | Actual Result | Evidence (Screenshot/Log) | PASS / FAIL / BLOCKED`.
3. **Deterministic Seed Dataset**:
   - **1 Admin**: `admin@logicq.io` (`role: 'ADMIN'`).
   - **6 Students**: Seeded across Sanjivani University departments (`AIML`, `AIDS`, `CSE`, `Integrated M.Tech`, `Mechanical`, `Integrated B.Tech`) and years (`FY`, `SY`, `TY`) with 12-digit PRNs and `prnIndex` records.
   - **16 Validated C Problems**: Including the current week's 7 scheduled daily challenges.

## 2. Part 1 — Feature-by-Feature Test Matrix (Normal, Invalid & Edge Cases)

Each feature must pass a **Normal Case**, **Invalid Input**, and **Edge Case**:

| ID | Feature Area | Normal Case | Invalid Input | Edge Case |
| :--- | :--- | :--- | :--- | :--- |
| **TP-01** | **Landing Page, Navbar & Removed Routes** | Matches `logicq.html` dark/light palette and SVG `<Logo />`; navbar displays strictly **Daily Challenge**, **Leaderboard** at `360px`, `768px`, and `1280px`; zero Arena, Archive, or Badges text/links/buttons on Landing Page or in built bundle. | Direct visits to `/archive`, `/arena`, `/arena/:id`, `/badges`, `/badges/*`, `/achievements`, or `/unknown-route` render the `404` page for logged-out users, students, and admins. | Contest, archive, and badge API endpoints reject calls from every role (`404 Not Found`); Firestore rules deny direct reads/writes to contest, archive, and badge collections (`badges`, `user_badges`). |
| **TP-02** | **PRN Sign Up & Academic Profile** | Valid 12-digit PRN, `Sanjivani University`, Department, Year, optional uppercase Division, and `@sanjivani.org.in` email create profile and atomic `prnIndex/{prn}`. | Fewer/more than 12 digits, non-digits, invalid department/year, or duplicate PRN rejected with clear field errors. | Google Sign-In user with `profileComplete: false` is redirected to `/complete-profile` and blocked from dashboard APIs (`403 PROFILE_INCOMPLETE`) until completed. |
| **TP-03** | **Sign In, Sign Out & Sessions** | Valid credentials sign in, refresh preserves session, show/hide password toggle works, logout clears session. | Wrong password rejected; banned user rejected (`403 ACCOUNT_SUSPENDED`). | Role change (`ADMIN -> STUDENT`) revokes existing JWT and forces re-login. |
| **TP-04** | **Weekly Catch-Up on Daily Challenge (`/challenge`)** | Compact 7-day strip on `/challenge` allows switching between and solving any already-unlocked challenge of the current week; solved challenges show checkmark. | Locked future days of the current week are disabled with their unlock timestamp (`17:00 IST`) and cannot be opened or fetched via API (`404`). | Past weeks' problems cannot be opened or fetched via `/api/problems/:slug` (`404`). |
| **TP-05** | **Student Dashboard & Past Weeks Summary** | Displays today's `17:00 IST` challenge, current streak, weekly points, weekly rank, **Past Weeks** selector for weekly result summary, solved counts, recent submissions, and activity heatmap (zero badge widgets or references). | Unauthenticated API fetch blocked (`401`). | Brand-new student with `0` solves sees clean empty state. |
| **TP-06** | **Problem Workspace & Monaco C Editor** | Renders sanitized Markdown statement, samples, constraints, `gcc -O2 -std=c11` flags; custom `logicq-dark` and `logicq-light` themes (`>= 4.5:1` line-number contrast); `Run Code` executes custom stdin. | Empty source code or >64KB payload rejected by Zod schema (`400`). | Sticky navbar (`--navbar-height: 4rem`) never clips the problem panel or line 1 of the Monaco editor at `360px`, `768px`, `1280px`, or `200%` zoom. |
| **TP-07** | **All 6 Judge Verdicts (No Badge Awards)** | `ACCEPTED` awards base points (+ same-day bonus if solved during the challenge's own 24h day) and updates streak & weekly rank without triggering any badge toast or badge award. | `COMPILE_ERROR` and `WRONG_ANSWER` return clear feedback without leaking hidden test inputs/outputs. | `TIME_LIMIT_EXCEEDED`, `RUNTIME_ERROR`, and `MEMORY_LIMIT_EXCEEDED` caught within sandbox limits. |
| **TP-08** | **Weekly Leaderboard & Past Weeks Selector** | Shows weekly rankings (`weeklyPoints` DESC, `lastAcSubmittedAt` ASC), Department/Year cohort filters, pinned student row with masked PRN (`••••••0001` only for self), percentile, and previous-week delta (zero badge icons or columns). | PRN and email are never exposed to other students on `/leaderboard` or `/profile/:id`. | **Past Weeks** selector (`Current Week`, `Last Week`, `2 Weeks Ago`, `3 Weeks Ago`) loads historical weekly rankings and student weekly summary metrics. |
| **TP-09** | **Submission History** | Shows student's own chronological submissions with verdict indicator, runtime (`ms`), timestamp, and source code viewer modal. | Attempt to query another student's `submissionId` via API or Firestore rules fails (`403` / `PERMISSION_DENIED`). | Empty state links directly to `/challenge` (no `/archive` or `/arena` links). |
| **TP-10** | **Admin Dashboard (No Contest/Archive/Badge Screens)** | Problem CRUD, daily scheduling, user management (including audited PRN/college updates with admin password re-auth), live submissions, rejudge, 2-Week Pilot Analytics, and audit log viewer. | Non-admin user blocked (`403`); contest, archive, and badge management screens are absent. | Exporting users and weekly results as CSV filters cleanly by Department, Year, Division, and College. |
| **TP-11** | **Privacy, Export & Delete** | **Export My Data** downloads JSON portfolio including PRN, academic fields, points, and submissions (no badge references); **Delete My Account** scrubs PII, frees `prnIndex/{prn}`, and anonymizes historical submissions. | Student cannot modify `prn` or `college` via `/api/users/me` (`403`). | Deleted student's freed PRN can be registered again by a new account. |
